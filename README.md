# NotasApp
 
Aplicación integradora del primer parcial (Presentación 6 – Persistencia local con SQLite), desarrollada con **.NET MAUI**, **Shell**, **MVVM** y **SQLite**. Permite crear, listar, editar y eliminar notas, y registra cada acción en un historial.
 
## Funcionalidades
 
- CRUD completo de notas almacenadas en SQLite.
- Confirmación antes de eliminar una nota.
- Historial que registra cada acción (crear, editar, eliminar) y se muestra en su propia pestaña.
- Validaciones: el título es obligatorio y tiene un máximo de 100 caracteres.
- Navegación con **Shell**: pestañas *Notas* e *Historial* y una ruta de detalle.
- Extra: búsqueda de notas por título con `SearchBar`.
## Tecnologías
 
- .NET MAUI (C# / XAML)
- Shell (TabBar y navegación por rutas)
- Patrón MVVM
- SQLite con `sqlite-net-pcl` y `SQLitePCLRaw.bundle_green`
